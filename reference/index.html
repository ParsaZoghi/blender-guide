When something goes wrong

You seeLikely causeFix
Bright pink surfaceImage file not foundFile › External Data › Find Missing Files, select the textures folder
Render is blackNo active camera, lights hidden from render, or all lights offCheck the camera icons in the Outliner; Ctrl+Numpad 0 on a camera
An object shows in the viewport but not the renderIts render toggle (camera icon) is offTurn the Outliner camera icon on (enable it in the Filter menu if hidden)
Glass looks black or greyToo few light bouncesRender › Light Paths › Max Bounces Total 16, Transmission 16
Grainy renderToo few samples for a dark sceneLower Noise Threshold, raise Max Samples, keep Denoise on
Bevel or Solidify unevenObject scale isn't 1Ctrl+A › Scale
Cloth explodes or flies awayUnapplied scale, or it starts intersecting the benchApply scale; start the cloth 1–2 cm above the seat; raise Quality Steps
Cloth passes through the seatSeat has no Collision, or the cloth is too coarseAdd Collision to the seat; more grid subdivisions; raise Quality
Flickering stripes where two surfaces meetZ-fightingMove one surface a few millimetres, like the arena floor at −0.005
Image looks stretchedPlane proportions don't match the imageSet Dimensions in the image's aspect ratio, or adjust a Mapping node
Bumps far too strong or masks softData image set to sRGBSet the Image Texture's Color Space to Non-Color
Dark patches or inside-out shadingFlipped normalsViewport Overlays › Face Orientation (red is the back side); Edit Mode › Shift+N recalculates
Can't find a panel you just usedAdjust Last Operation closedF9, or Ctrl+Z and redo

Glossary

Active object
The last selected object; many commands act on it.
Apply
Make a transform or modifier permanent in the mesh.
Bevel
Rounding off a sharp edge.
BSDF
The maths describing how a surface scatters light. Principled BSDF is Blender's all-in-one version.
Collision
Physics setting that makes an object solid for cloth.
Cycles · EEVEE
Blender's accurate, slower renderer · its fast, real-time renderer.
Depth of field
Blur in front of and behind the focus point, controlled by the F-stop.
Displacement
Moving real geometry using a texture. Bump only fakes it with shading.
Emission
A surface that gives off light.
Empty
An invisible object used as a handle or target.
Interpolation
How Blender fills in values between keyframes.
IOR
Index of refraction: how much glass bends light (window glass is about 1.52).
Keyframe
A stored value at a specific frame.
Linear values
Blender's internal colour numbers, which differ from screen hex codes.
Manifold
A closed, watertight mesh: every edge is shared by exactly two faces, with no holes or internal faces.
Mesh island
A group of connected vertices. "One island" means every part is joined to every other part.
Modifier
A non-destructive operation stacked on an object.
Node
One building block in a material, world or other node tree.
Non-Color
Image setting for data (heights, masks) rather than visible colours.
Normal
The direction a face points; also the input for fake bumps.
Origin
An object's pivot point (the orange dot).
Parent
An object that others follow.
Pin group
The cloth vertices held in place during a simulation.
Primitive
A ready-made starting shape (cube, sphere…).
Procedural texture
A pattern generated by maths (Noise, Voronoi, Wave), with no image file.
Polycount
How many faces a model has. Game engines draw every face every frame, so game models stay inside a face budget.
Quad
A four-sided face; the best kind for subdivision.
Sample
One ray-traced measurement per pixel; more samples, less noise.
Subsurface scattering
Light travelling under a surface before exiting, as in skin and fruit.
Three-point lighting
Key, fill and rim lights around a subject.
UV map
The flattened layout that places an image on a 3D surface.
Z-fighting
Flicker when two surfaces occupy the same place.

Values in this guide were read from basketball_court.blend, clothes.blend, fruits.blend, warmobile.blend and epidaurus.blend as saved in your repository, opened in Blender 5.2.2. Menu names follow Blender 5.2; if a label differs slightly in your version, F3 search finds the command by name.
